# knights-and-knaves-solver
A Python solver for Knights and Knaves puzzles using propositional logic and truth tables.A Python solver for Knights and Knaves puzzles using propositional logic and truth tables.

the program takes symbolic statements from A and B (p = "A is a knight",
q = "B is a knight"), builds a truth table, highlights the
consistent rows, and prints the solution in plain English.

## Run
to run the program, run python main.py
